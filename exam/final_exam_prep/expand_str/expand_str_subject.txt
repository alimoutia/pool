Assignment name  : expand_str
Expected files   : expand_str.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string as a command-line argument and displays it
with exactly three spaces between each word, with no spaces or tabs at the
beginning or at the end, followed by a newline.

A "word" is defined as a section of a string delimited by spaces/tabs or by
the start/end of the string.

If the number of command-line arguments is not 1, or if there are no words,
the program displays a newline.

Examples:

$> ./expand_str "See? It's easy to print same thing" | cat -e
See?   It's   easy   to   print   same   thing$
$> ./expand_str "   this        time it     is    more   complex  " | cat -e
this   time   it   is   more   complex$
$> ./expand_str "No extra space" | cat -e
No   extra   space$
$> ./expand_str "" | cat -e
$
