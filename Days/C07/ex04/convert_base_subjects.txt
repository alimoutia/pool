Assignment name  : ft_convert_base
Expected files   : ft_convert_base.c, ft_convert_base2.c
Allowed functions: malloc, free
--------------------------------------------------------------------------------

Write a function that returns the result of the conversion of the string nptr
from the base base_from to the base base_to.

1. nptr can be preceded by arbitrary whitespaces or multiple '+' / '-' signs.
2. Parsing stops at the first character not present in base_from.
3. The bases (base_from and base_to) must follow these validation rules:
   - Base size must be at least 2.
   - Base cannot contain duplicate characters.
   - Base cannot contain '+', '-', or whitespaces (space, \t, \n, \v, \f, \r).

If base_from or base_to are invalid, or if memory allocation fails, the
function returns NULL.

Function Prototype:

char *ft_convert_base(char *nbr, char *base_from, char *base_to);
